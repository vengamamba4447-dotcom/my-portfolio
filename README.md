# Vengamamba Bandi — Portfolio Website

## 1. Open in VS Code
1. Extract `vengamamba_portfolio.zip`.
2. Open VS Code.
3. Select **File → Open Folder** and choose the extracted `vengamamba_portfolio` folder.

## 2. Add your profile photo
1. Choose a clear, professional photo.
2. Rename the image to `profile.jpg`.
3. Put it inside the `assets` folder, replacing the placeholder instructions if needed.
4. Refresh the website. If the image is missing, the page shows a VB initials placeholder.

Use a JPG image for the simplest setup. A square or portrait image works well.

## 3. Preview the website
1. In VS Code, install the **Live Server** extension if you do not already have it.
2. Open `index.html`.
3. Right-click and select **Open with Live Server**.
4. Your browser should open the portfolio. Resize the browser to test the mobile layout.

You can also open `index.html` directly in a browser, but Live Server is more convenient while editing.

## 4. Add your resume
Your resume PDF is included at `assets/resume.pdf`. The Download Resume buttons use this file.

## 5. Update LinkedIn
In `script.js`, replace `https://www.linkedin.com/` with the full URL of your LinkedIn profile. Save the file and refresh the page.

## 6. Add the project repository
When you upload your Student Result Management System code to GitHub, replace the project link in `index.html` with that specific repository URL.

## 7. Publish with GitHub Pages
1. Create a GitHub repository, for example `my-portfolio`.
2. Upload the contents of this folder (including `index.html`, `style.css`, `script.js`, and `assets`).
3. In the repository, open **Settings → Pages**.
4. Under build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the published URL to appear in the Pages section.

Before publishing, confirm that you want your email and resume publicly visible.
